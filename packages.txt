# MONOLITH Dotfiles - package manifest
#
# Derived from the configuration files. A program is listed as
# "required" only when an ACTIVE binding, autostart entry, script or module calls it.
# Commented-out or unused entries were deliberately NOT promoted (see docs/DEPENDENCIAS.md).
#
# Format
#   [<source>:<scope>]      source = official | aur ; scope = required | optional
#   package-name  # why it is needed
#   [manual]                software that is not available as a package, or user-owned files
#                           that must be copied by hand
#
# Notes
#   * "official" = Arch repositories (core/extra/multilib). The installer never runs
#     'pacman -Sy' (partial upgrades are unsupported on Arch): run 'sudo pacman -Syu' first
#     if a package is reported as not found.
#   * "aur" entries are only built when an AUR helper (paru / yay) is available. Some of
#     them may already exist in the official repositories; the installer checks
#     'pacman -Si' first and uses pacman when the package is there.
#   * Parsed by scripts/lib/packages.sh - keep one package per line.
