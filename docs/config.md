# Desktop configuration

[Português (Brasil)](configuracao.md) · **English**

`configs/` mirrors paths under your home directory: `configs/.config/` is deployed to `~/.config/`, and `configs/.local/bin/` to `~/.local/bin/`. The installer copies the contents; it does not generate or adapt settings for your hardware.

## What is included

| Folder | Contents |
|---|---|
| `hypr/` | Modular Hyprland setup in Lua, lock screen, idle settings, portal and Rofi themes |
| `quickshell/` | Bar, settings menus, network, Bluetooth, audio, brightness, notifications and system modules |
| `fish/` | Fish setup, Hyprland startup on TTY1, Starship, Atuin and completions |
| `ghostty/` | Terminal settings and cursor shaders |
| `gtk-3.0/`, `gtk-4.0/`, `nwg-look/` | Appearance and preferences for GTK applications |
| `nvim/`, `micro/`, `btop/` | Neovim startup with LazyVim, Micro editor and resource monitor |
| `wal/`, `wpg/` | Settings for wallpaper-derived themes |

`wallpapers/` contains media shipped separately from the configuration payload. `scripts/import-configs.sh` can copy selected folders from your `~/.config` into the repository payload; this is optional.

## Review before installing

The configuration contains local choices that may not match your machine:

- `hypr/modules/monitors.lua` selects the preferred output, automatic position and scale `1`. Adjust it if your monitor layout needs something else.
- `hypr/modules/environment.lua` sets `LANG` and `LC_TIME` to `pt_BR.UTF-8`. That locale must exist on the system; the installer warns but does not generate it.
- `hypr/modules/input.lua` contains keyboard and input preferences. Review the layout and values before using them.
- `fish/config.fish` starts Hyprland on TTY1 under the conditions defined in the file. This depends on your login shell and how you start the session.
- `hypr/modules/keybindings.lua` contains shortcuts and local commands. Confirm that the associated programs are installed.

The compositor entry point is `hypr/hyprland.lua`. Quickshell starts at `quickshell/shell.qml`; its bar and components live in `components/`, `modules/`, `menus/`, `services/` and `core/`.

## Wallpapers

The `SUPER+D` shortcut opens the Rofi menu configured in `hypr/rofi/wallpaper-menu.rasi` and runs `~/.local/bin/wallpaper-menu`.

| Type | Destination in your home directory | Engine |
|---|---|---|
| Static | `~/Pictures/Wallpapers` | `awww` |
| `.mp4` video | `~/Videos/wallpaper-live` | `mpvpaper` |

The installer creates these destinations and copies the wallpapers shipped with the project. The menu uses `ffmpeg` to generate cached previews; `wallpaper-menu --clear-cache` clears the cache.

### Colour themes

Settings > Themes switches between the original Monolith theme, preset themes and a dynamic palette. The dynamic palette comes from the wallpaper changed most recently, on any monitor: `~/.local/bin/monolith-theme` runs `wpgtk` in its own folder (`~/.cache/monolith-theme`), so it never sets wallpapers or touches `~/.config/wpg`. For videos it reads one representative frame when the video is chosen. The choice and the palette are saved in `~/.local/state/quickshell-monolith/settings.json`; `fish/conf.d/monolith-theme.fish` applies the same colours to Fish, in new and open sessions. `monolith-theme check` lists the dependencies and `monolith-theme clear-cache` removes the generated palettes.

## Import exclusions

The importer avoids copying some machine-specific data and artefacts, including:

| Path or pattern | Why it is excluded |
|---|---|
| `micro/backups/` | May contain versions of any file you edited. |
| `fish/fish_variables` | May store private variables and machine paths. |
| `fish/conf.d/*.env.fish` | Generated by third-party installers and may contain local paths. |
| `*.bak`, `*~`, `*.swp`, `*.tmp`, `*.log`, `__pycache__`, `.git`, `.DS_Store` | Temporary backups and local artefacts. |

These exclusions are applied by the importer; they do not replace a manual review before publishing. Do not add tokens, keys, credentials, email addresses or private paths to the project.

## Settings app

`Super` menu → **Settings** (or `qs ipc call shell settings <page>`). Pages: System, Display, Hyprland, Bar, Audio,
Microphone, Widgets, Notifications, Network, Bluetooth, Power (laptops only), Storage, Input and Update.

- **Display** and **Hyprland** apply changes live through the Hyprland Lua API (`hyprctl eval`) and save them in
  `~/.config/hypr/generated/monitors.lua` and `~/.config/hypr/generated/settings.lua`. `hyprland.lua` loads both
  files last. Delete a file to go back to your own `modules/*.lua`. A monitor change reverts after 15 seconds
  unless you click **Keep**.
- **Microphone** has RNNoise noise suppression (package `noise-suppression-for-voice`, adjustable strength)
  and a 5-band equalizer (100 Hz – 8 kHz, ±12 dB, with an 80 Hz high-pass) with presets, including *Deep voice*.
  Drag a band, scroll over it (±1 dB) or double-click it (0 dB); **Undo changes** returns to the values from
  when the page was opened; **Reset** goes back to flat. The effects expose the input **Monolith Mic**, which
  becomes the default while they are on; picking another input then changes the mic being filtered. **Listen to the mic** plays the default input back through
  `pw-loopback` (optional 0.3 / 1 s delay, stops after 2 min); use headphones. Logs: `[micfx]` / `[mictest]`
  in the Quickshell log, `journalctl --user -u monolith-micfx`.
- **Audio** has the same equalizer for the output (10 bands, 31 Hz – 16 kHz) with presets (Bass boost, Extreme
  bass, Funk, Trap, Rock, Vocal boost, Deep house, ASMR, Pop, Electronic, Jazz, Classical, Lo-fi, Podcast, Late
  night, Treble). The **More effects** drawer holds bass boost, volume boost (pre-gain; high values can clip) and
  two headphone effects: the virtualizer (moves the music away: less direct sound, softer highs and reverb) and
  **8D** (the music circles the head, with an adjustable time per turn). The output **Monolith Audio** becomes the default while the effects are
  on, and picking another output changes the device it plays into.
- **Effect persistence**: each chain is a PipeWire filter-chain run by a systemd user unit
  (`~/.config/systemd/user/monolith-micfx.service` / `monolith-audiofx.service`, `WantedBy=pipewire.service`)
  that reads `~/.local/state/quickshell-monolith/micfx.conf` / `audiofx.conf`. Every change is saved at once and
  the effects start with PipeWire at login, even when the shell is stopped or restarting. Turning the effects
  off disables and removes the unit. Logs: `[micfx]` / `[audiofx]` / `[mictest]`,
  `journalctl --user -u monolith-audiofx`.
- **Bar style** (Settings → Bar): *Flat* (full-width strip), *Capsule* (a rounded pill with a margin from the
  screen edges; on a side bar it is a vertical pill) or *Frame* (the bar continues as a thin border around the
  whole screen with rounded inner corners, Caelestia style). Only the background changes, not the modules.
  Capsule and Frame can cast a shadow (*Bar shadow*, *Shadow strength*). The frame is opaque; *Frame tone* goes
  from black (0 %) to the theme colour (100 %), and the modules switch to light or dark shades of the theme's
  own colours to stay legible on it.
- **Center menu** (Settings → Bar → *Center menu*): resting the pointer on the middle of the bar opens a panel
  with the clock and date, weather (wttr.in; set a city or leave it empty for automatic), CPU / RAM / GPU gauges
  and history, the player and the uptime. It closes when the pointer leaves it. It is created only while open,
  so it costs nothing when closed. `qs ipc call shell toggle center` opens it pinned.
- **Desktop widgets** (Settings → Widgets): clock, system, weather and media widgets on the desktop, under the
  windows. **Arrange widgets** (or `qs ipc call widgets edit`) opens the editor: drag to move (snaps to an 8 px
  grid), × to remove, the toolbar adds more; Esc or **Done** leaves it. Positions are saved per monitor in
  `settings.json`. A new widget type is one QML file in `quickshell/widgets/` plus one line in
  `services/Widgets.qml`.
- **Storage** reads disk health from UDisks2, without root. Cleanup always scans first and lists what each item
  removes. Removing needs a second, confirming click. pacman and journal cleanup ask for the password through
  `pkexec`.
- **Update** compares the local clone with its own remote and branch: the upstream if one is set, otherwise
  `origin/<branch>`. It also reports the GitHub API status and rate limit.
- **YouTube Music** (th-ch desktop app) does not expose shuffle or repeat over MPRIS. To use those buttons,
  enable its *API Server* plugin and either set authorization to *No authorization* or paste a token in
  Settings → Bar. The default port is 26538.
- Covers of the last 50 played tracks are cached in `~/.cache/quickshell-monolith/covers`.
- **Player title** grows with the track name between a minimum and a maximum number of characters
  (Settings → Bar → *Player title: minimum / maximum*). In the media menu, the title font shrinks for long
  names and grows for short ones.
- **Recently played**: clicking a track sends it to the current player over MPRIS (`OpenUri`) and presses Play
  until it starts, so players that only load the page (YouTube Music) start playback too. Players without
  `OpenUri` fall back to the browser.
- **Bluetooth scan** keeps the request alive for 60 s: if BlueZ drops discovery right after it starts, the shell
  asks again by itself, so one click on **Scan** is enough.

## Network requests made by the shell

The shell contacts the services below, and only when the feature that needs them is in use. Each one can be turned
off; nothing else leaves the machine.

| Feature | Service | What is sent | When | Turn off |
|---|---|---|---|---|
| Weather (center menu, weather widget) | `api.open-meteo.com`, `air-quality-api.open-meteo.com` | latitude and longitude | when the tab or widget is shown, at most every 20 minutes | Settings > Bar > Center menu (no weather widget, center menu off) |
| Weather: city lookup | `geocoding-api.open-meteo.com` | the city typed in Settings | once per city | leave the city empty |
| Weather: location without a city | `ipinfo.io` | your IP address (it is the request itself) | when no city is set | Settings > Bar > Center menu > *Weather: locate by IP* (off: no weather until a city is set) |
| Lyrics | `lrclib.net`, `music.163.com` (NetEase), `api.lyrics.ovh` | artist, title, album and length of the playing track | when lyrics are shown; results are cached | one switch per source in Settings > Bar > Player; all off = no request |
| Album covers | the URL the player publishes (MPRIS `artUrl`) | a plain download | when a track enters the history | — (the address comes from your player) |
| Update check (Arch, CachyOS) | your clone's `origin` remote, `api.github.com` | a `git fetch` and one anonymous API request | when Settings > Update is opened | do not open the page |
| YouTube Music controls | `127.0.0.1` (the player's API Server plugin) | local only | when YouTube Music is the player | — |

Before an update runs, Settings > Update lists the commits it brings (and says when the installer itself changes)
and asks for a second click; the clone is then fast-forwarded to exactly the listed revision. The command line of
the center menu keeps its history in `settings.json`; *Keep the command history* (Settings > Bar > Center menu)
turns that off and clears what was saved.
